# new.22codex.xyz 首页拓扑

- 目标：`https://new.22codex.xyz/` 深色模式，桌面基准 `1440 × 1000`。
- 宿主导航：固定于顶部，`64px` 高；自定义首页从页面顶部开始，首屏内容自行预留导航空间。
- 自定义首页：单一 `.xa-home` 根节点，共 8 个 `section`。
- 首屏：左右双栏，左侧网关说明卡，右侧立体控制台卡。
- 首屏下方：四列数据带。
- 后续：能力卡片、接入流程、工具矩阵、控制室、FAQ、CTA。
- 交互：宿主导航固定；自定义首页本身以静态展示和链接跳转为主。
- 响应式：桌面双栏；窄屏转单栏，工具与数据带换行。
